Item Catalog Backend
 Overview

This is the backend for the Item Catalog web application.
It is built using the MERN stack, providing APIs for product management, user authentication, and cart functionality. Alo this application is having CRUD operations for Admin.

 Technologies Used

Node.js – runtime environment

Express.js – web framework

MongoDB – database for storing product and user details

Mongoose – MongoDB object modeling

JWT (JSON Web Token) – for user authentication

Cloudinary  – for image storage

dotenv – for managing environment variables

Cors & bcryptjs – for secure communication and password hashing
